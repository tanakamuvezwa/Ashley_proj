# MBONGOCIRCLE Holdings Limited ("MBONGOCIRCLE")
### AI-Powered Financial Marketplace & "Uber for Loans & Project Investments"

MBONGOCIRCLE is an Artificial Intelligence-powered financial marketplace that transforms how individuals, businesses, institutional investors, and financial institutions discover, negotiate, and transact financial products across Zimbabwe and the Southern African Development Community (SADC).

---

## 🚀 Key Features

1. **Uber for Loans & Capital Bidding Engine**: Real-time AI matching connecting project owners & borrowers with competing banks, microfinance institutions, and angel investors.
2. **Project Pitch & Idea Marketplace**: Platform to showcase Zimbabwean & SADC projects, agricultural ventures, solar infrastructure, and tech startups seeking debt/equity capital.
3. **Institutional Portal**: Workbench for banks (CBZ, Stanbic, NMB, Old Mutual) to place bids, automate underwriting criteria, and disburse capital.
4. **Embedded Financial Suite**: Cross-border FX converter (ZWG, USD, ZAR, BWP), instant asset insurance quotes, and digital payment infrastructure preview.
5. **Mobile & Web App Experience**: Integrated responsive interface with an interactive **Mobile App Frame Simulator**.

## 🛠️ Local Development Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

## 📦 How to Upload to GitHub

1. Initialize git (if not already initialized):
   ```bash
   git init
   git add .
   git commit -m "Initial commit: MBONGOCIRCLE AI Financial Marketplace"
   ```

2. Link to your GitHub repository and push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_GITHUB_USERNAME/mbongocircle.git
   git push -u origin main
   ```

## ☁️ How to Deploy to Vercel

### Option 1: Vercel CLI (Fastest)
1. Install Vercel CLI: `npm i -g vercel`
2. Run command in this directory:
   ```bash
   vercel
   ```
3. Follow prompts. It will automatically detect `vercel.json` and deploy in 30 seconds!

### Option 2: Vercel Web Dashboard
1. Go to [vercel.com/new](https://vercel.com/new)
2. Connect your GitHub account and import your `mbongocircle` repository.
3. Click **Deploy**. Vercel will automatically build and publish your website.
